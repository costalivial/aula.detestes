# Aula de CSS — Moranguinho e suas Amigas 🍓

Este é um projeto simples de uma página web estruturada em HTML5, desenvolvido como um exercício prático para aplicação de estilos em CSS. A página apresenta a personagem **Moranguinho** e a sua turma, disponibilizando links diretos para vídeos de cada uma delas no YouTube.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Alinhamento, estilização e paginação (configurado no arquivo externo `style.css`).
